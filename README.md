# Expense Tracker with AI Insights

## Overview
A full-stack web application that helps users track expenses, manage budgets, and gain AI-driven financial insights. The app identifies unnecessary spending and suggests smarter alternatives to save money.

## Features
- User Authentication (Signup/Login)
- Add, Edit, Delete Expenses
- Expense Categorization
- Necessary vs Unnecessary Expense Detection
- AI-Based Alternative Suggestions
- Budget Tracking with Alerts
- Interactive Dashboard with Charts
- Multi-Currency Support (USD, INR, EUR, GBP)
- Monthly Report Download (CSV)
- Analytics and Spending Trends
- Financial Health Score

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Chart.js

### Backend
- Flask (Python)

### Database
- PostgreSQL
- SQLAlchemy
